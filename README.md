Proyecto Calculadora

Descripción

Este proyecto consiste en una calculadora básica desarrollada como parte de la materia Introducción a la Programación. Su objetivo es realizar operaciones matemáticas básicas de una manera sencilla.

Autor

Daniel Garcia

Contenido del repositorio

* README.md: contiene la información y descripción del proyecto.
* calculadora.cpp: contiene el código fuente de la calculadora.

Cómo ejecutar o revisar el proyecto

Para ejecutar el proyecto, se debe abrir el archivo calculadora.cpp utilizando un compilador de C++. Después, se puede compilar y ejecutar el programa para utilizar la calculadora.
